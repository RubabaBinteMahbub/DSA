# Data Structures Linked Lists: Insertion, Deletion, Reversal. Stacks: Array-based and Linked List-based. Trees: Binary Search Tree (BST) operations. Heaps: Max-Heap and Min-Heap for Priority Queues. Algorithms Sorting: O(nlogn) algorithms like Merge Sort and Quick Sort. Search: Linear Search and Binary Search. Graph Theory: Shortest path algorithms and connectivity tests. Types): Use of Classes/Structs to define data types and their associated behaviors. 📋 Key Data Structures Included 1. Linked Data Structures Singly Linked List: Node-based storage with forward pointers. Doubly Linked List: Bi-directional navigation using next and prev pointers. Circular Linked List: Tail node pointing back to the head. 2. Stack & Queue (ADTs) Stack: Array-based and Linked List-based implementations of LIFO. Queue: Linear and Circular implementations of FIFO. 3. Tree Structures Binary Search Tree (BST): Ordered tree structure for efficient lookup. Heaps: Complete binary trees used for priority management. 4. Graphs Adjacency Matrix: 2D array representation. Adjacency List: Array of linked lists/vectors representing connections.
